# Italiano Replay

유튜브 영상의 선택 구간을 문장별로 듣고 반복하는 초급 이탈리아어 학습 사이트입니다.

## 사용 방법

1. `dist/index.html`을 브라우저에서 엽니다.
2. 오른쪽 문장을 누르면 해당 구간만 재생됩니다.
3. `반복 켜짐` 상태에서는 선택한 문장이 계속 반복됩니다.
4. 재생속도는 `1×`와 `1.25×` 사이에서 전환할 수 있습니다.

## GitHub Pages에 올리기

1. 새 GitHub 저장소를 만듭니다.
2. `dist/index.html`을 저장소의 최상위 경로에 `index.html`이라는 이름으로 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 설정합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.

별도의 설치나 빌드 과정은 필요하지 않습니다.
